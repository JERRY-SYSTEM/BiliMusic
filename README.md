# BiliMusic

基于 Flutter 开发的哔哩哔哩音频播放器。

## 功能

- [x] 歌曲搜索和播放
- [x] 账号登录与收藏夹同步
- [x] 自建歌单
- [x] 自定义歌名、歌手和歌词
- [x] 歌词搜索
- [x] 多主题设置
- [x] 缓存管理
- [x] 数据导入和导出
- [x] 支持Android和iOS端
- [ ] etc...

## 下载与安装

- **[最新版本](https://github.com/JERRY-SYSTEM/BiliMusic/releases/latest)**

---

### Android 安装

仅支持arm64-v8a。

1. 在 Latest Release 页面下载 `bilimusic-x.x.x-arm64-v8a.apk` 安装包。
2. 在 Android 设备安装下载的 `.apk` 文件（需 Android 6.0 及以上版本，由于签名使用的是LSPatch默认签名，因此可能会误报为病毒）。

### iOS 安装

BiliMusic 未上架 Apple App Store，发布构建以未签名归档包（`bilimusic-x.x.x-unsigned.ipa`）形式提供。建议使用 [LiveContainer](https://livecontainer.github.io) 安装。

1. 按照 [视频教程](https://b23.tv/owg4oOo) 或 [文字教程](https://www.luvwan.com/7848.html) 安装LiveContainer。
2. 在首页导入 `.ipa` 文件，启动。
